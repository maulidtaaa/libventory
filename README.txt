## Fitur
- Splash screen HTML/CSS/JS
- Dashboard total barang
- Statistik Baik, Rusak Ringan, Rusak Berat
- Tambah inventaris
- Daftar inventaris
- Edit data
- Hapus data dengan konfirmasi
- Pencarian nama dan kode inventaris
- Filter ruangan
- Filter kondisi
- Dark mode
- Export JSON
- Import JSON
- Statistik grafik sederhana
- Backup dan restore melalui JSON
- LocalStorage
- PWA manifest
- Service worker
- Responsive mobile dan desktop
- Tombol install PWA jika browser mendukung

## Menjalankan
Untuk pengujian PWA, gunakan server lokal. Contoh:
- VS Code + Live Server
- Laragon
- Python HTTP server

Jangan membuka file langsung dengan file:// karena Service Worker membutuhkan secure context seperti localhost atau HTTPS.
